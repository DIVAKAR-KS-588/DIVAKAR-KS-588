GITHUB PROFILE DESIGN — QUICK START (Windows)

CONTENTS
- README.md: animated GitHub profile design
- assets/: put your own banner images/GIFs here

STEP 1 — CREATE THE SPECIAL REPOSITORY
1. Go to https://github.com/new
2. Repository name: DIVAKAR-KS-588
3. Set Public.
4. Do NOT tick "Add a README file" if you plan to push this folder as-is.
   If you already created the repository with a README, use the alternative note below.
5. Create repository.

STEP 2 — INSTALL GIT (if needed)
Open PowerShell and run:
    git --version
If it says command not found, install Git from https://git-scm.com/download/win,
then close and reopen PowerShell.

STEP 3 — EXTRACT THIS ZIP
Extract the ZIP somewhere easy, such as:
    C:\Users\YOUR-USERNAME\Documents\github-profile-design

STEP 4 — OPEN POWERSHELL IN THE EXTRACTED FOLDER
In File Explorer, open the github-profile-design folder.
Click the address bar, type powershell, and press Enter.

STEP 5 — PUBLISH
Run these commands one at a time:
    git init
    git branch -M main
    git add README.md
    git commit -m "Create animated GitHub profile README"
    git remote add origin https://github.com/DIVAKAR-KS-588/DIVAKAR-KS-588.git
    git push -u origin main

If prompted, sign in to GitHub in the browser/credential manager.

IF YOU ALREADY CREATED THE GITHUB REPOSITORY WITH A README
Use this alternative before pushing, if the remote contains only that starter README:
    git pull origin main --allow-unrelated-histories
Resolve any conflict if Git reports one, then commit and push.
If unsure, ask for help before running additional commands.
